
# Top Replit AI Prompts to Build Better Projects

These high-impact prompts are designed to be used with Replit Ghostwriter or ChatGPT to make your project development faster, cleaner, and more efficient.

## Core Development Prompts

### 1. Build me a project that does X, using Y tech.
→ Build me a full-stack to-do list app using React for the frontend and Flask for the backend, with a SQLite database.

### 2. Refactor this code to be cleaner, faster, and more secure.
→ Use it to improve messy or old code for better readability and performance.

### 3. Add error handling and input validation to this function.
→ Improves code stability and prevents user errors.

### 4. Write tests for this function/module.
→ Creates unit tests to ensure reliability and correctness.

### 5. Create a dark mode/light mode toggle for this site.
→ Adds a professional look and feel to your UI.

### 6. Explain what this code does, step by step.
→ Helps you learn or debug unfamiliar code.

### 7. Connect this frontend to the backend API at [URL] and show data here [DOM location].
→ Quickly links frontend with backend APIs without manual setup.

### 8. Scan this codebase and tell me what's unused, broken, or poorly organized.
→ Acts like an AI-powered code reviewer.

### 9. Give me a launch checklist for this web app (including deployment, performance, and security).
→ Helps ensure your project is production-ready.

### 10. Generate OpenGraph/meta tags for this page and explain SEO improvements.
→ Improves how your site appears in search engines and social shares.

## Bonus Developer Prompts

• How can I make this app scalable for thousands of users?

• Turn this synchronous function into an async version with proper error handling.

• Where are the bottlenecks in this code, and how can I fix them?

• How can I implement authentication securely with OAuth or JWT?

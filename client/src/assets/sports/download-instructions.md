
# Sports Icons Download Instructions

To populate this folder with professional sports league icons, download SVG icons for:

## Major Sports Leagues:
1. **Basketball**: NBA, WNBA, EuroLeague
2. **Football**: NFL, NCAA Football
3. **Baseball**: MLB, NPB (Japan), KBO (Korea)
4. **Hockey**: NHL, KHL (Russia)
5. **Soccer**: FIFA, UEFA, Premier League, La Liga, Serie A, Bundesliga, Ligue 1, MLS
6. **Tennis**: ATP, WTA, Grand Slams
7. **Golf**: PGA Tour, European Tour
8. **Motorsports**: Formula 1, NASCAR, IndyCar
9. **Combat Sports**: UFC, Boxing federations
10. **Olympic Sports**: IOC, Paralympics

## File Naming Convention:
- Use lowercase with hyphens: `premier-league.svg`
- League logos: `nba-logo.svg`
- Sport general: `basketball.svg`

## Recommended Sources:
- Official league websites
- Sports databases with licensing
- Vector icon libraries
- Wikimedia Commons (public domain)

## Image Requirements:
- Format: SVG preferred (scalable)
- Size: 512x512px minimum
- Background: Transparent
- Quality: Official/licensed when possible

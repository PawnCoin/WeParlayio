# 🔍 Full Site Audit Instructions for Replit AI

## 🎯 Goal
Run a full audit on this project and fix **anything** that prevents the site from being 100% functional and user-friendly.

## ✅ What to Audit
- Pages: Home, Odds, Parlays, About, Contact, Any Dynamic Pages
- APIs: /api/odds, /api/parlays, /api/games, any external fetches

## 🧪 Check for:
- Broken buttons or inputs (nothing happens on click, wrong data)
- API calls that return null, undefined, or errors
- Components that don’t render or are blank
- Console errors or uncaught exceptions
- Broken links or 404s
- Missing event listeners
- Styling bugs that break layout

## 🔧 What to Do:
- Connect or repair broken button actions
- Fix API fetches or create missing endpoints
- Create or fix any missing front-end components
- Resolve all console/browser errors
- Make the site fully functional

## 🧰 Tools You Can Use
- HTML, CSS, JavaScript
- fetch() for frontend API
- Express or your server for backend logic
- Logs, console, and browser testing
